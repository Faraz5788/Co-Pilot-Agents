# Christmas Team Quiz: Mentimeter version (multiple choice)

**How to build it in Mentimeter**
1. **New presentation → + New slide → Quiz → Select answer**.
2. Paste the question, add the 4 options and tick the ✅ correct one.
3. Set the timer to **20 seconds** (30 for longer questions). Leave **Leaderboard** on: Mentimeter adds a leaderboard slide after each question; you can delete all but one per round.
4. Add a **Heading** slide for each round title (🎬 Round 1: Christmas Films, etc.).
5. Present, and people join at **menti.com** with the code shown on screen.

**Tip: you don't need all 50.** About 20 questions (4 per round) takes 15–20 minutes with leaderboards. The ⭐ questions are the most fun picks if you want a shorter quiz.
